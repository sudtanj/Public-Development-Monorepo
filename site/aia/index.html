App Inventor app

This page loads an App Inventor or Thunkable Classic app straight from its .aia export. The screen is drawn from the app's designer file, and its blocks (button taps, timers, web requests) run in a small in-browser interpreter. Features that need phone hardware or cloud services that no longer exist (CamVision, emotion and image recognition) can't run in a browser, so they're written to the event log instead.
